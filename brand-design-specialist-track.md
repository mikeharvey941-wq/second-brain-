# Specialization Track: Brand & Visual Design Systems
### Runs parallel to the main curriculum in `agent-building-learning-schedule.md` — not after it.

**Why parallel, not sequential:** Design literacy doesn't require terminal/git/Python fluency to begin. Starting it alongside Phase 1-2 means that by the time you reach Phase 3 (content generator) and Phase 5 (build your own harness), you have a real, specific thing to build agents *for* — not a generic exercise. Your OHPAH brand work (the Old World Firehouse manual, the locked type/color system, the brand voice manifesto) is already art-school-meets-marketing-MBA in practice. This track formalizes the method behind what you've already been doing intuitively, so you can repeat it for any brand, on demand, not just OHPAH.

**End state:** an agent/harness — built by you, using the skills from the main curriculum — that takes a one-paragraph brief and produces a full brand collection: mood direction, palette, type pairing, logo concepts, verbal identity, and an assembled brand book.

## Module A — Design Literacy Fundamentals
*(runs alongside main Phase 1-2, roughly Weeks 3-9)*

### A1. Typography systems
- **Objective:** Understand type pairing logic — display vs. body vs. technical/numeral faces, hierarchy, and why certain combinations read as "premium heritage" vs. "modern tech" vs. "playful."
- **Why:** You've already locked a system (Cinzel for wordmark, Adobe Caslon for headings, Baskerville for body, Clarendon Bold for numerals). This module is about understanding *why* that combination works structurally — contrast in weight, era, and function — so you can make that call confidently for the next brand without reverse-engineering it from vibes.
- **Exercise:** Take your own OHPAH type system and write out, in your own words, what role each typeface plays and why it's not interchangeable with another. Then find one brand you admire and reverse-engineer its type logic the same way.
- **Checkpoint:** Given a brief ("heritage industrial, trustworthy, not corporate"), propose a 3-typeface system with a one-line justification for each, without looking anything up first.

### A2. Color theory and palette construction
- **Objective:** Learn contrast, temperature, and restraint — how a locked palette (like Deep Navy/Walnut/Canvas/Parchment) creates consistency, and how isolating an accent color (like Firehouse Red to the LOG button only) creates meaning through scarcity.
- **Why:** Palette work is where most self-taught brand design goes wrong — either too many colors or no rationale for the ones chosen.
- **Exercise:** Build 2 alternate palettes for a fictional brand brief, each with a one-paragraph rationale for every color's role (primary, accent, neutral, restricted-use).
- **Checkpoint:** Explain, for your own locked OHPAH palette, why Firehouse Red is restricted rather than used throughout — in terms of meaning, not just aesthetics.

### A3. Layout, composition, and grid systems
- **Objective:** Understand whitespace, visual hierarchy, and grid logic — why your timeline dashboard spec (squared cards, flat fills, no color-coded severity) reads as calm and clinical rather than busy.
- **Exercise:** Take one screen from a brand/app you admire and annotate its grid and hierarchy by hand (screenshot + markup).
- **Checkpoint:** Redraw one OHPAH screen spec from a blank layout, arriving independently at a similar structure to the locked spec.

### A4. Verbal identity and brand voice methodology
- **Objective:** Formalize what you did intuitively for OHPAH's brand voice manifesto (short declarative sentences, no em dashes, no "wellness" language, no exclamation points) into a repeatable process: define the *forbidden* words/patterns before the *preferred* ones.
- **Why:** A voice guide that only lists what to say is weak. One that also locks what's banned (and why) is what makes brand copy consistent across writers, including an AI.
- **Exercise:** Write a one-page verbal identity brief for a fictional brand, structured as: tone in 3 adjectives, 5 banned words/patterns with reasons, 5 example lines, 2 closing lines (B2C/B2B style, like "Your Record. Always.").
- **Checkpoint:** Someone else (or an AI with no context) can write one on-brand sentence from your brief alone.

### A5. Systematic moodboarding and reference research
- **Objective:** Learn to pull references with intent — era, industry-adjacent-but-not-competitor, texture sources — instead of "vibes I like."
- **Exercise:** Build a 12-image moodboard for a brief with a one-line reason each image is included (what specific element it contributes — texture, type, color, composition).
- **Checkpoint:** Someone unfamiliar with the brief can guess the intended tone from your moodboard alone.

## Module B — Tool Fluency
*(runs alongside main Phase 2-3, roughly Weeks 6-14)*

You already have these connectors available — this module is about deliberate fluency, not first contact.

### B1. Figma
- Learn components, variables, and design systems thinking — not just moving shapes.
- Practice using Figma together with Claude Code for design-to-code handoff: pull design context/specs from a Figma file and have Claude Code translate it into actual component code.
- **Checkpoint:** Build one small component system in Figma (e.g., a button with 3 states) and have Claude Code implement it in code from the Figma spec alone.

### B2. Adobe for creativity tools
- Learn image generation, background removal, vectorization (turning a raster logo sketch into clean SVG), and font-matching tools.
- Directly useful for logo work: sketch a concept, vectorize it, refine.
- **Checkpoint:** Take one rough logo idea from sketch to clean vector.

### B3. Higgsfield (deepen beyond current use)
- You already use this for partner-spotlight text corrections. Extend to full asset generation: mood imagery, texture generation, multiple aspect ratios for a single campaign.
- **Checkpoint:** Generate a 3-image mood set for a brief, consistent in palette and texture, using reference-image chaining.

### B4. Canva (for speed work)
- Learn when template-based generation is the right tool (fast, good-enough social assets) vs. when custom design work is warranted — an important judgment call, not just a tool skill.
- **Checkpoint:** Produce one week's worth of social assets in under an hour using Canva, reserving custom Higgsfield/Adobe work for the hero pieces only.

## Module C — Brand System Methodology
*(runs alongside main Phase 3, roughly Weeks 10-16)*

### C1. The repeatable process
Formalize a 4-stage process you can run for any brand, including future ones beyond OHPAH:
1. **Discovery** — positioning, audience, competitive gap (you've already done this rigorously for OHPAH in the positioning gap map)
2. **Direction** — 3 distinct mood directions presented with rationale, not just one guess
3. **System** — locked type pairing, palette, texture/pattern library, logo lockup variations
4. **Collection** — applied assets: website mockup, social templates, a mockup of one physical/print application, and an assembled brand book document

### C2. Exercise: redo OHPAH's brand system from scratch
- **Objective:** Run your own new methodical process against a brand you already know intimately, to feel the difference between "arrived at intuitively" and "arrived at systematically."
- **Checkpoint:** Your redone system should converge close to the actual locked OHPAH system — if it doesn't, that's useful data on where your instinct and your method disagree.

### C3. Exercise: run the full process on a brief you don't already know
- **Objective:** Prove the method works when you don't have the answer memorized.
- **Checkpoint:** A complete, presentable brand direction deck for a fictional brand, in under a week of part-time work.

## Module D — Capstone: The Brand-Generation Agent
*(overlaps main Phase 5 — harness-building, roughly Weeks 17-22)*

This is where the two tracks fuse. Instead of a generic harness exercise, you build the harness *for this specific domain* — which means you'll actually use it afterward.

- **Objective:** Build an agent/harness that takes a one-paragraph brief (audience, mission, tone) as input and outputs:
  1. Three mood board directions (image generation, tied to Module A5's reference logic)
  2. A locked color palette with rationale (Module A2's method, applied automatically)
  3. Type pairing suggestions, cross-checked against what's actually available/licensed (via Adobe/Figma font tools)
  4. Logo concept directions (image generation → vectorization)
  5. A verbal identity doc (Module A4's banned/preferred word method)
  6. All of it assembled into one brand book document (this is where your docx/PDF skill fluency from the main curriculum pays off directly)
- **Why this is the right capstone:** It's not a toy. It's a tool you would actually use again — for the next brand extension, a client, or a future product. It's also the clearest possible demonstration that you've internalized both tracks: the harness mechanics from the main curriculum, and the design method from this one.
- **Checkpoint:** Run the agent on a brief it hasn't seen, and get a brand direction you'd be comfortable presenting to a client with only light manual polish.

## Module E — Ongoing: Portfolio and Positioning
*(Week 23+, alongside main Phase 6-7)*

- Build 2-3 full brand collections using your agent, for fictional or real small clients, as a portfolio.
- Honestly evaluate whether "AI-assisted brand studio for first-responder-adjacent or industrial-heritage brands" becomes a real second offering — you'd be combining a niche you already deeply understand (occupational health / heritage industrial aesthetics) with a capability almost nobody else has built end-to-end.
- This does not need to become a business decision now — just keep the evidence (the portfolio pieces) so the decision is informed later, not speculative.
