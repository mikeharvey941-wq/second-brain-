# Second Brain

Second Brain is a multi-agent harness — a coordinated team of specialist agents (Router, Positioning, Narrative, Visual Direction, Copy/Formatting, Brand QA, Document Assembly, and Research/Grounding), each matched to the model best suited for its job. Rather than one generalist agent doing everything, each specialist handles a single task well, coordinated by a Router that sequences work and persists state across runs. The first two verticals built on this shared architecture are a personal brand system (positioning, narrative, and platform-specific content for Michael Harvey, founder of EMR Inc.) and a company brand system (OHPAH's brand voice, visual identity, and content generation). The long-term goal is a reusable second-brain architecture that can support additional verticals — including a future wellness app — without rebuilding the underlying agent and tool layer each time.
